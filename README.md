# Handling CBR XML API Data Streams

Учебный проект на Python по работе с XML-данными Центрального банка РФ.

## Цель

Получение данных о курсах валют через XML API ЦБ РФ, их обработка и представление в различных форматах.

## Что реализовано

* получение XML-данных через HTTP-запрос;
* разбор XML с помощью `xml.etree.ElementTree`;
* выбор валют по их идентификаторам;
* работа с классами и свойствами;
* применение паттерна **Decorator**;
* преобразование данных в JSON;
* преобразование данных в CSV с использованием `pandas`.

## Структура

Основная реализация находится в `main.py`.

В проекте представлены:

* `Component` — базовый компонент;
* `ConcreteComponent` — получение и обработка данных о валютах;
* `Decorator` — базовый декоратор;
* `ConcreteDecoratorJSON` — представление данных в JSON;
* `ConcreteDecoratorCSV` — представление данных в CSV.

## Технологии

* Python
* XML
* `requests`
* `xml.etree.ElementTree`
* `pandas`
* JSON
* паттерн проектирования Decorator

## Результат

Проект позволил на практике изучить получение данных из внешнего API, обработку XML и применение паттерна Decorator для расширения функциональности объекта без изменения его исходной реализации.
